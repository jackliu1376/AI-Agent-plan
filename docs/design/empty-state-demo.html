动画规格

元素参数意图
背景极光两团 blur(60px) 色斑（380 / 340px），周期 19s / 24s，位移 ±50px，透明度 0.46让画面是「活」的。聚焦输入框时提到 0.74 —— 效果和交互挂钩，不只是背景装饰
3D 倾斜perspective: 1500px；rotateX 9° rotateY -13° rotateZ 1.6°，加在**整块台面**上参考图那种「产品在动」的观感来源。倾斜必须放在台面而不是逐张卡片，见下面的性能说明
鼠标视差鼠标位置映射到 ±4° / ±5.5°，transition .38s倾斜跟着鼠标走，空间感是真的
卡片入场上浮 10px + 缩放 .97 → 1，间隔 130ms，共 1s一次性
卡片漂浮±5px + 再偏 0.5°，周期 9 / 9.5 / 10 / 10.5 / 11 / 12 / 12.5 / 13s相位与周期都错开，避免整齐划一的机械感。关键帧里必须带上各自的 --r，否则一跑动画卡片就被「扶正」
卡片混排8 个元素、5 种形状：药丸卡 ×2 / 竖版照片卡 / 白卡 ×2（图标+大数字+状态药丸）/ 深色玻璃卡 / 渐变面板 / 小圆徽章参考图那块区域没有连线、没有统一网格，是一堆不同形状的卡叠在一起。混排 + 叠压就是它「高级」的来源
各自角度--r 从 -7° 到 +7°，z-index 1→6 六层统一角度会变成规整网格；角度不一致才有「随手撒在桌上」的感觉
照片卡166×206，白 3px 描边 + 大投影，object-fit: cover整块拼贴的视觉锚点。没有照片会像占位图
渐变面板径向点阵（13px 网格）+ 150° 线性渐变，右侧溢出 16px参考图右边那块蓝紫面板的对应物。溢出边界让画面「没被框住」
配色切换侧栏底部一个两段式分段控件（色块 + 文字），选中态白底 + 发丝线；折叠后竖排、只留色块这是**产品里的真控件**，不是图纸开关。放侧栏是因为它是常驻偏好；放光区里的话一旦有了计划就够不着了
配色作用域**只作用于光区**（极光 / 药丸卡 / 面板 / 徽章 / 图标）外面那些彩色是**语义色**：绿=完成、玫瑰=要注意、琥珀=进行中。它们不能跟着主题变，否则「绿=完成」这条约定就废了。所以这不是妥协，是正确
切换过渡瞬时（无过渡）CSS 不能对 linear-gradient() 做过渡，渐变只能硬切。图标那种纯色倒是能过渡。要做交叉淡入淡出得叠两层极光 —— 两倍的 blur() 开销，前面已经证明这条路会掉层，不值
图形来源图标是内联 SVG，照片是生成后压缩到 480×720 / 91 KB图标用矢量：能跟着配色开关变色、任何缩放都锐利。照片只此一张
示例轮播三条示例交叉淡入淡出，各 4.8s，含 4px 位移就是你说的「渐入渐出」。顺带把固定的 placeholder 换成了会换的例子
石堆水印260px，opacity .07，13s 呼吸（缩放 1→1.045）品牌隐喻。项目没有图片素材，用大号 logo 当水印最稳

四个必须知道的代价
① 会破现有令牌。 styles.css 开头写死了「没有渐变、没有阴影堆叠」。这里的做法是把它关进 .hero-zone——入口可以炫，工作区保持安静。整页铺开会失去层次。
② 性能——这条不是理论风险，画这版图纸时就踩到了。 第一版卡片上带了 backdrop-filter、极光是 blur(84px)、外面还套着 preserve-3d： 结果 4 张卡片里只有 1 张被画出来（DOM 里在、opacity:1、位置也对，就是不上屏）。 A/B 一测发现每次跑的结果还不一样 —— 这是合成层被随机丢弃，不是 CSS 写错。 去掉 backdrop-filter、blur 降到 60px 后稳了一版； 但把倾斜从 9° 加到 13° 时又复发—— 说明真正的元凶是 preserve-3d： 它让每张卡各自成为一个 3D 层，层数一多 Chromium 就开始丢。 改法：倾斜加在整块台面上，去掉 preserve-3d 与 translateZ， 计划卡改用 scale(1.04) 表达「更近」。视觉上几乎无差别，连跑 3 轮不再丢。
③ 触屏没有鼠标。 视差要关掉（图纸里已按 hover: hover 自动降级），触屏上退化成静态倾斜。
④ 蓝紫不在现有色板里。 勾上「换成品牌暖色」能对比：暖色版更贴现有气质但没那么「科技」，蓝紫更抓眼但和侧栏的暖灰底有轻微冲突。
