名字 · Cairn /kern/ —— 徒步时用石头堆起的路标。它和这个项目是同一件事： 一块一块垒起来（每个事实都经工具查证）、只用手里真有的石头（查不到就说查不到，绝不编造）、 立在不熟悉的地形里（任务越模糊越要先澄清）。名字在 AI 领域已验证无撞名。

这一版改了什么：① 进度不再输出「轮次≤8 · 工具≤12 / 预算 1/12 / get_weather_forecast」这类内部实现，换成「已查证 3 项 + 人话结果」； ② 主色从高饱和蓝换成近黑，玫瑰色只留给「需要你注意」；③ 去掉卡片套卡片，用发丝线和留白分区； ④ 步骤改为「编号 + 动作 + 标签」的扫读结构，依赖关系从裸 ID 变成可读的「依赖 S2」； ⑤ 补上左侧栏，让「最近的任务」有地方待 —— 现在重开一次就全丢了； ⑥ 侧栏可折叠（品牌行右侧按钮），208px → 60px：品牌只留标记，新建任务收成图标， 历史条目收成首字方块（认得出是哪个任务，只留圆点会认不出），把宽度让给计划正文。
